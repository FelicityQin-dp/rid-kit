# LAMMPS custom-CV example

This directory contains a minimal 4-atom Lennard-Jones chain example for running RiD with the LAMMPS engine.

## Files

- `conf_000.lmp`: initial LAMMPS data file
- `input_explore.lammps`: exploration MD input script
- `input_label.lammps`: restrained label MD input script
- `colvar`: custom PLUMED CV definitions

Both LAMMPS scripts must:

- read `conf.lmp` in the task directory
- load `plumed.dat` generated by rid-kit
- write trajectory to `out.dump`
- write log to `log.lammps`
- let PLUMED write `plm.out`

## Submit

```bash
rid submit -i ./lj4_lmp_input -c ./rid_json_files/rid_lj4_lmp.json -m machine_bohrium_lmp_k8s.json
```

Before submitting, replace `YOUR_LMP_PLUMED_IMAGE` in `machine_bohrium_lmp_k8s.json` with a LAMMPS+PLUMED image built from `install/lmp_exploration_dp.dockerfile`.

## Notes

- This example uses `ExploreMDConfig.type = lmp` and `LabelMDConfig.type = lmp`.
- Label uses `method = restrained`; LAMMPS does not support `constrained` label in rid-kit.
- Selector uses `slice_mode = dpdata` for LAMMPS trajectories.
- `std_threshold` in `rid_lj4_lmp.json` uses the default scalar threshold from `LabelMDConfig`.
